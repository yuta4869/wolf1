Command

Pick one of the allowlisted commands and fill in the arguments. The browser sends a JSON payload to /api/command; the server re-enters the existing CLI handler. No shell, no subprocess.

Settings

      

        Stored at .wolf/config/settings.json under the
        current project root. Tokens / access_token / refresh_token
        / client_secret / api_key are rejected by
        the server.
      

      

      
      

    


    
    

      
Files

      

        Entry points for the v0.1 file commands. Paths must live
        under --project-root; secrets / .env /
        credentials / tokens / private are denied by the
        SensitivePathGuard.
      

      

        
        
        
      

    


    
    

      
Mail

      

        Local .eml / .mbox / Maildir. Never sends. Drafts are
        returned as text the user copies into their real client.
      

      

        
        
        
        
      

    


    
    

      
Gmail

      

        Default backend is fake (no network). Real Gmail
        requires a credentials_path JSON file with
        {"access_token": "..."} — wolf never refreshes
        the token and never sends mail.
      

      

        
        
        
        
        
      

    


    
    

      
Audit

      

        Live tail of var/audit/audit.jsonl via
        /api/audit-tail. The CLI handler is the source
        of truth — body bytes and tokens are never re-injected here.
